# Divine Guidance Website

This is a static website for a tarot, numerology, and healing consultation service. It is designed to be hosted on GitHub Pages.

## Files

- `index.html` – main page structure
- `styles.css` – styling and layout
- `script.js` – small page behavior

## GitHub Pages setup

1. Push the project to a GitHub repository.
2. Go to the repository settings.
3. Open **Pages**.
4. Set the source to **Deploy from a branch**.
5. Select the main branch and the root folder (`/`).
6. Save and wait for GitHub to publish the site.

## Google Form integration

The booking section includes a placeholder Google Form link:

`https://forms.gle/your-google-form-link`

Replace it with your real Google Form link after you create the form in Google Forms.
